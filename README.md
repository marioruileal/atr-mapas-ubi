# atr-mapas-ubi

Páginas das provas da Ultra Blue Island 2027 (Azores Trail Run): perfil interativo, mapa com três fundos (Relevo, Trilhos e Fotografia aérea) e GPX para descarregar.

- Separado do site em construção: só tem estas cinco páginas e os ficheiros do mapa.
- Gerado a partir do repositório privado `atr-documentos` (`site-maquetas/prova-interativa/publicar_pages.py`); não se edita aqui.
- Mapa: OpenStreetMap (© contribuidores do OpenStreetMap), OpenTopoMap (CC-BY-SA), CyclOSM e Ortofotomapa 2024 © Governo dos Açores (SRAAC), CC BY 4.0.
